# 即时零售

#### Description
本项目基于前后端分离架构开发，后端采用模块化设计，涵盖用户服务、商家服务、商品服务、订单服务、配送调度服务、支付结算服务、消息通知服务等核心模块，支持高并发下单与实时履约状态同步。前端适配用户端（H5/小程序/APP）、商家端、运营管理端多端展示、配送路径规划、动态计价引擎、商家/骑手/平台多方分账、权限与数据隔离等能力。系统代码结构清晰、接口规范，便于客户团队后续维护、扩展与自主上线部署。
